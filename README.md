# Study with Cat Mimi!! 🐱✨

A cozy, pixel-art themed Pomodoro timer built with pure HTML, CSS & JavaScript.
Stay focused and productive while Cat Mimi keeps you company!

## Features
- 🍅 Pomodoro (25 min), Long Break (10 min) & Short Break (5 min) timers
- 🔔 Bell alarm when any session ends
- 📝 sticky notes panel to jot down tasks
- 🎯 Daily session goal tracker with progress bar
- 🎵 One-click lofi playlist via Spotify
- 💡 Rotating study tips from Mimi
- ⭐ Animated pixel art cat + twinkling star background

## Usage
Just open `index.html` in your browser — no install, no dependencies.
To link your own Spotify playlist, replace the URL in the `PLAYLIST_URL` 
variable at the top of the script.

## Built with
HTML · CSS · Vanilla JavaScript · Web Audio API
